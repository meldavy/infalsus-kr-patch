# Core Terms — Authoritative Glossary (JP → KO)

Rules: before translating a chapter, look up every recurring noun here.
New terms discovered while translating get ADDED immediately. If a decision
changes late, grep all `translation/ko/*.txt` for the old rendering and fix
retroactively — consistency across all 235 stories is the hard part of this
project; a term, name, honorific or speech level must render identically
everywhere unless the original deliberately shifts it.

## Style conventions

- Dialogue quotes: JP 「」 → Korean `"` `"`. Inner quotes 『』 → `'` `'`.
- Ellipses: JP `……` → keep as `……` (two chars). Trailing dashes `───` kept.
- Long vowel names follow 국립국어원 일본어 표기법: ソウスケ→소스케, オオヤギ→오야기,
  トウコ→토코, ヴ→비 (ヘルヴィ→헬비).
- First-person: narrator/POV character uses 나 in narration. Dialogue
  first-person varies by speaker register — see `docs/characters.md`.

Punctuation, hanja-gloss and line-structure rules are kept separately —
this file is nouns only.
